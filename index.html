🐙 GitHub · Repositorio privado

Todos los datos (historial, locales, vendedores, armadores) y la base de productos se guardan en tu repositorio privado, dentro de la carpeta indicada: productos.json y convenio.json.

Crea un token fine-grained solo para ese repositorio con permiso Contents: Read and write. Se guarda únicamente en este navegador; nunca se incluye en el HTML ni se sube a GitHub.
☁️ Conexión a Supabase

Ingresa los datos de tu proyecto de Supabase (los encuentras en Project Settings → API). Se guardan solo en este navegador.

Inicia sesión con la cuenta que creaste en Supabase (Authentication → Users) para que solo tú puedas leer o guardar datos.
